# Did more efficient steam engines make Britain burn more coal?

Just show me the answer

TRUE

**True.** In *The Coal Question* (1865), the economist William Stanley Jevons observed that England's coal use soared after more efficient steam engines expanded coal's industrial uses.

Tell someone: Jevons observed in 1865 that more efficient steam engines made coal cheaper to use, so Britain found new uses and burned more of it.

## What's the version people tell?

The popular version is an assumption rather than a story. A more efficient engine burns less coal for each job, so a country with better engines should burn less coal.
